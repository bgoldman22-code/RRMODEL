PATCH NOTES - NFL Blobs Fix

This patch does four things:
1. Pins @netlify/blobs to 7.2.0 (known-good with Netlify Functions)
2. Removes @netlify/blobs from external_node_modules so esbuild bundles it
3. Adds version-agnostic helpers for Blobs (CJS + ESM)
4. Adds a minimal health-blobs-min function for diagnostics

How to Apply:
1. Unzip into your repo root (preserve paths)
2. Commit changes to GitHub
3. In Netlify, trigger a 'Clear cache and deploy site'
4. Test at /.netlify/functions/health-blobs-min

Sanity Check:
- If working, you'll see {"ok":true,...,"tests":[{"step":"write-read","ok":true}]}.
- If failing, it will show {"ok":false,...}.
