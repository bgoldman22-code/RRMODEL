# Environment Variables Setup Guide

## TheOddsAPI Integration

To enable real sportsbook odds instead of model-only predictions:

### 1. Get API Key
- Visit: https://the-odds-api.com/
- Sign up for free account (500 requests/month)
- Get your API key from dashboard

### 2. Local Development
Create `.env.local` in your project root:

```bash
# TheOddsAPI Key - DO NOT COMMIT TO GIT
REACT_APP_ODDS_API_KEY=your_api_key_here_replace_this
```

### 3. Production Deployment (GitHub Pages)
Since GitHub Pages doesn't support server-side environment variables, you have two options:

#### Option A: Build-time Environment (Recommended)
Add your API key to GitHub Secrets:
1. Go to your repository Settings → Secrets and variables → Actions
2. Create secret: `REACT_APP_ODDS_API_KEY` with your API key
3. In your build workflow, add:
   ```yaml
   - name: Build
     run: npm run build
     env:
       REACT_APP_ODDS_API_KEY: ${{ secrets.REACT_APP_ODDS_API_KEY }}
   ```

#### Option B: Client-side with Netlify Functions (Current Setup)
The system will fallback to position-based estimates when no API key is provided.

### 4. API Rate Limits
- Free tier: 500 requests/month
- Each player prediction = 1 request
- Cache enabled (5 minute expiry) to reduce API calls
- Fallback to model estimates when rate limit exceeded

### 5. Environment Check
The system will log:
- ✅ "Using live odds from TheOddsAPI" when API key works
- ⚠️ "Using fallback odds - API key missing" when no key
- ❌ "API rate limit exceeded" when quota exhausted

### Security Notes
- Never commit API keys to Git
- Use GitHub Secrets for production
- API key is only visible in browser network requests (acceptable for free tier)
- Consider server-side proxy for production apps with sensitive keys
