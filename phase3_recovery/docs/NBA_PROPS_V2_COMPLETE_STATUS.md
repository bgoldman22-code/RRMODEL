## 🚀 Automation Options (Not Yet Implemented)

### Option 1: GitHub Actions (Recommended - Scheduled Automation)

**Status:** ✅ READY TO IMPLEMENT

Create `.github/workflows/nba-props-v2-daily.yml`:

```yaml
name: NBA Props V2 Daily Update
on:
  schedule:
    - cron: '0 14 * * *'  # 9 AM ET daily (14:00 UTC)
  workflow_dispatch:  # Allow manual trigger

jobs:
  update-predictions:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v3
      
      - uses: actions/setup-node@v3
        with:
          node-version: '18'
      
      - name: Update boxscores (2025-26)
        run: node scripts/nba/fetch-player-boxscores-2025-26.mjs --daily
      
      - name: Generate V2 predictions
        env:
          ODDS_API_KEY: ${{ secrets.ODDS_API_KEY }}
        run: node scripts/nba/generate-pra-predictions-v2.mjs
      
      - name: Commit and push changes
        run: |
          git config user.name "GitHub Actions"
          git config user.email "actions@github.com"
          git add data/nba/*.json public/data/nba/nba-props-v2-live.json
          git commit -m "Auto-update NBA Props V2 - $(date +%Y-%m-%d)" || exit 0
          git push
```

**What You Need:**
1. Add `ODDS_API_KEY` to GitHub repository secrets
2. Create the YAML file in `.github/workflows/`

### Option 2: Server-Side Refresh in Netlify Function (On-Demand)

**Status:** ✅ READY TO IMPLEMENT

Enhance `netlify/functions/nba-props-v2.mjs` to support `?refresh=1`:

```javascript
// netlify/functions/nba-props-v2.mjs
import { execSync } from 'child_process';
import fs from 'fs';
import path from 'path';

export async function handler(event) {
  const headers = {
    'Access-Control-Allow-Origin': '*',
    'Content-Type': 'application/json',
    'Cache-Control': 'public, max-age=300'
  };

  try {
    // Check if refresh requested
    const shouldRefresh = event.queryStringParameters?.refresh === '1';
    
    if (shouldRefresh) {
      // Only allow if ODDS_API_KEY is set
      if (!process.env.ODDS_API_KEY) {
        return {
          statusCode: 403,
          headers,
          body: JSON.stringify({ error: 'Refresh not available - ODDS_API_KEY not configured' })
        };
      }
      
      console.log('🔄 Refreshing V2 predictions...');
      
      // Run generator script server-side
      execSync('node scripts/nba/generate-pra-predictions-v2.mjs', {
        env: { ...process.env, ODDS_API_KEY: process.env.ODDS_API_KEY },
        stdio: 'inherit'
      });
      
      console.log('✅ Predictions refreshed!');
    }
    
    // Load and return predictions
    const filePath = path.join(process.cwd(), 'public/data/nba/nba-props-v2-live.json');
    const data = fs.readFileSync(filePath, 'utf-8');
    
    return {
      statusCode: 200,
      headers,
      body: data
    };
    
  } catch (error) {
    console.error('Error:', error);
    return {
      statusCode: 500,
      headers,
      body: JSON.stringify({ error: 'Failed to load predictions' })
    };
  }
}
```

**Frontend Change:** Add "Force Refresh" button in `src/pages/NBAPlayerPropsV2.jsx`:

```javascript
const forceRefresh = async () => {
  setLoading(true);

  } catch (error) {
    alert('❌ Refresh failed: ' + error.message);
  } finally {
    setLoading(false);
  }
};

// In the UI:
<button onClick={forceRefresh} className="bg-purple-600 text-white px-4 py-1.5 rounded">
  🔄 Force Refresh
</button>
```

**What You Need:**
1. Set `ODDS_API_KEY` in Netlify environment variables
2. Update the Netlify function code
3. Add refresh button to frontend

**Pros:**
- ✅ Real-time refresh capability
- ✅ On-demand updates anytime
- ✅ No GitHub Action needed

**Cons:**
- ❌ Costs Netlify function execution time (~10-30 seconds)
- ❌ TheOddsAPI rate limits apply
- ❌ Slower user experience during refresh

3. Git Commit & Push
   └─ Triggers Netlify auto-deploy
