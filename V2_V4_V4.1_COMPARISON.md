## WHY ML MARKET STILL FAILS

**Root Cause:** Information Loss in Spread→ML Conversion

```
Spread = HFA + f(EPA, Success, Explosive, ...)
ML = g(Spread)  ← LOSES CONTEXT

Better approach:
ML = h(EPA, Success, Explosive, HFA, QB, Weather, Rest, ...)  ← DIRECT
```

**Current Formula:**
```javascript
p_home = 0.53 + (spread * 0.025)
```

**Problems:**
1. Assumes linear relationship (it's not)
2. Ignores game context (weather, injuries, rest)
3. Fixed 53% HFA (varies by team/venue)
4. No uncertainty modeling (tight games different from blowouts)

**Solution (V5):**
```javascript
p_home = logistic(
  b0 + b1*epa_diff + b2*third_down_diff + 
  b3*rz_td_diff + b4*pressure_diff + 
  b5*qb_epa + b6*HFA + b7*rest + b8*weather
)
// Train coefficients b0...b8 via ridge regression
```
