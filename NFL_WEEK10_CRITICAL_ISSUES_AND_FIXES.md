```javascript
// V5 Quantile-Based Total Model (REAL)
function estimateTeamDistribution(teamFeatures, isHome) {
  const epaOffense = teamFeatures[`${isHome ? 'home' : 'away'}_epa_offense`] || 0
  const epaDefense = teamFeatures[`${isHome ? 'home' : 'away'}_epa_defense`] || 0
  
  // EPA to points conversion (empirical: 0.1 EPA ≈ 2.4 points/game)
  const basePoints = 21.5 + (epaOffense * 24) - (epaDefense * 12)
  
  // Pace adjustment (possessions per game)
  const explosiveRate = teamFeatures[`${isHome ? 'home' : 'away'}_explosive_rate`] || 0.12
  const thirdDownRate = teamFeatures[`${isHome ? 'home' : 'away'}_third_down_success`] || 0.40
  
  const paceFactor = 1.0 + (explosiveRate - 0.12) * 5 + (thirdDownRate - 0.40) * 2
  const possessions = 12 * paceFactor
  
  // Points variance (higher for offenses with big play ability)
  const variance = 5.0 + explosiveRate * 20
  const stdDev = variance / Math.sqrt(possessions / 12)
  
  return {
    p25: mean - 0.675 * stdDev,  // 25th percentile
    p50: mean,                     // Median
    p75: mean + 0.675 * stdDev,   // 75th percentile
    possessions
  }
}

// Weighted blend: 60% mid, 20% low, 20% high
const blended = mid * 0.60 + low * 0.20 + high * 0.20

// Confidence based on distribution spread (NOT FIXED)
const spread = high - low
const confidence = 0.50 + Math.min(0.20, 10 / spread) // Tighter = higher confidence
```

### 8. ⚠️ **Linear EPA Scaling (0.5) Is Not Calibrated**

**Issue:** Throwaway script uses:
```javascript
const epa_spread = (home.net_epa - away.net_epa) * 0.5 + 2.5
```

**Reality Check:**
- EPA → spread relationship is **non-linear**
- Strong teams (>10 EPA diff) don't scale 1:1
- Weak matchups (<-5 EPA diff) regress faster
- Context matters (injuries, QB, weather)

**Proper Calibration:**
```javascript
// Fit from historical 2020-2024 data
const epaToSpread = isotonic_regression(
  X = historical_epa_diff,
  y = historical_closing_spread
)

// Apply non-linear mapping
const model_spread = epaToSpread(home_net_epa - away_net_epa) + HFA
```

**Example from Real Data:**
| EPA Diff | Linear (0.5) | Actual Market | Error |
|----------|--------------|---------------|-------|
| +30 | 15.0 + 2.5 = 17.5 | 14.5 | +3.0 overestimate |
| +10 | 5.0 + 2.5 = 7.5 | 7.0 | +0.5 |
| 0 | 0.0 + 2.5 = 2.5 | 2.5 | ✓ |
| -10 | -5.0 + 2.5 = -2.5 | -3.0 | +0.5 underestimate |

**Fix:** Use spline or isotonic regression fitted on historical data.

**Status:** 🟡 **MEDIUM** - Affects large favorites/underdogs
