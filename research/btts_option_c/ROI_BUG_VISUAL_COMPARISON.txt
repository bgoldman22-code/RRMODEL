THEORETICAL SANITY CHECK:
--------------------------

Question: Can you really make 3198% ROI on sports betting?

Analysis:
  • Max single-bet profit with typical odds (1.60-2.20): ~120%
  • To achieve 3198% aggregate ROI, you'd need to:
    - Win 97% of bets at 2.0 odds, OR
    - Win 80% of bets at 40.0 odds (absurd for BTTS)
  
  • Actual Poisson performance:
    - Wins 78.6% at odds ~1.80
    - Math: (0.786 * 80 - 0.214 * 100) / 100 = 41.48% per bet
    - Over 426 bets: ~31.98% aggregate ROI ✅
  
Verdict: 3198% is mathematically impossible. 31.98% is realistic.


CODE BUG LOCATION:
------------------

File: (terminal output, used to generate markdown)
Line: Analysis aggregation script

# WRONG:
roi_fair = 31.98  # From CSV (already percentage)
print(f"Fair ROI: {roi_fair:.2%}")  # Outputs "3198.26%"

# CORRECT:
roi_fair = 31.98  # From CSV (already percentage)
print(f"Fair ROI: {roi_fair:.2f}%")  # Outputs "31.98%"

The .2% format specifier means "multiply by 100 and add %"
Since the CSV already stores as percentage, this double-multiplies!
