## ROOT CAUSE: ML MARKET FAILURE

**Problem:** Simple spread→ML conversion doesn't work
- V2/V4.1 formula: `p = 0.53 + spread * 0.025` 
- Assumes linear relationship (each point = 2.5% probability)
- **Reality:** Relationship is non-linear and context-dependent

**Why it fails:**
1. **Information loss** - Spread collapses many factors into one number
2. **No game context** - Injuries, weather, matchup-specific factors
3. **Fixed HFA** - 53% home advantage regardless of team/venue
4. **No uncertainty modeling** - Close games (spread ±3) need different treatment

**Evidence:**
- 32% ML accuracy = Worse than betting all favorites (40-45% expected)
- -39% ROI = Massive systematic bias
- 0.33 monotonicity = Little edge→win relationship

## V5 STRATEGY: DIRECT MODELING

Instead of deriving ML from spread, **model it directly**:

### Phase 1: Direct ML Model

**Approach:** Logistic regression with rich features
```javascript
// V5 ML Model (not derived from spread)
p_home = logistic(
  b0 +
  b1*epa_offense_diff +
  b2*epa_defense_diff +
  b3*third_down_success_diff +
  b4*red_zone_td_rate_diff +
  b5*pressure_rate_diff +
  b6*explosive_play_diff +
  b7*qb_epa_diff +
  b8*home_field_advantage +
  b9*rest_days_diff +
  b10*weather_factor
)
```

**Training:**
- Ridge regression (L2 regularization) to prevent overfitting
- 5-fold cross-validation (time-based splits)
- Optimize for log loss (proper scoring rule for probabilities)

**Expected Outcome:** 50-55% ML accuracy, -5% to +5% ROI

### Phase 2: Enhanced Total Model

**Approach:** Pace-adjusted scoring projection
```javascript
// V5 Total Model
total = 
  base_pace_adjusted_scoring +
  14*(EPA_offense_sum) -
  10*(EPA_defense_sum) +
  8*(explosive_play_rate_sum) +
  6*(red_zone_efficiency_sum) +
  pace_multiplier*(possessions_expected) +
  weather_adjustment +
  rest_adjustment
```

**Key Additions:**
- **Pace factor** - Fast teams (PHI, BUF) inflate totals
- **Weather** - Wind, rain, temp affect passing games
- **Rest** - Thursday games score ~3-4 fewer points

**Expected Outcome:** 53-56% total accuracy, +2% to +5% ROI
